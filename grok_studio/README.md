# 🎬 Grok Studio — 쇼핑몰 모델 영상 생성기

그록(xAI Grok Imagine) API 하나로:

1. **모델 3명** 중 한 명을 고르고
2. **옷 사진**을 올리면
3. 그록이 옷을 분석해 → **그 모델이 옷을 입은 사진**을 만들고
4. 정해진 **영상 프롬프트(안무)** 대로 → **영상**을 만들어 줍니다.

기존 `AI Employee OS` 와는 **독립된 별도 앱**입니다. 같은 저장소에 얹혀 있을 뿐,
서로 영향을 주지 않습니다.

---

## 빠른 시작

```bash
pip install -r requirements.txt         # 저장소 루트에서 (fastapi/uvicorn/requests 등)

# .env 에 그록 키 넣기
cp .env.example .env
#   XAI_API_KEY=xai-...        ← 본인 키

python -m grok_studio.app                # → http://127.0.0.1:8100
```

브라우저에서 열고 → 모델 클릭 → 옷 사진 업로드 → **🎬 영상 만들기**.
진행이 단계별로 표시되고, **옷 입은 사진 → 영상** 순서로 결과가 나옵니다.

---

## 파이프라인 (3단계)

| 단계 | 하는 일 | 사용 API |
|---|---|---|
| ① 옷 분석 | 업로드 사진에서 옷만 상세 묘사 | `chat/completions` (비전) |
| ② 옷 입히기 | 선택한 모델이 그 옷을 입은 사진 생성 | `images/generations` |
| ③ 영상 | 그 사진 + 안무 프롬프트로 영상 | `videos/generations` (Grok Imagine) |

각 모델의 외모는 `models.py` 의 `appearance` 문구로 **고정**됩니다.
문구가 구체적일수록 매번 같은 모델이 나옵니다. 모델을 바꾸려면 이 파일만 편집하세요.

---

## 영상 프롬프트(안무)

기본 안무는 `models.py` 의 `DEFAULT_MOTION_PROMPT` 이며, 화면에서 바로 수정 가능합니다:

> 40도 회전 → 0.5초 정지 → 같은 방향 40도 더 회전 → 0.5초 정지 →
> 카메라 쪽으로 돌아와 1초 정지 → 왼쪽으로 걸어 화면 밖으로 퇴장.

## 설정 (.env)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `XAI_API_KEY` | — | **필수.** 그록 키 |
| `XAI_VISION_MODEL` | `grok-2-vision-1212` | 옷 분석 |
| `XAI_IMAGE_MODEL` | `grok-2-image-1212` | 옷 입은 사진 |
| `XAI_VIDEO_MODEL` | `grok-imagine-video` | 영상 |
| `XAI_VIDEO_DURATION` | `10` | 영상 길이(초) |
| `XAI_VIDEO_ASPECT_RATIO` | `9:16` | 세로영상 |
| `APP_PASSWORD` | (없음) | 사이트 접속 비번(선택) |

> xAI 가 모델 식별자나 엔드포인트 경로를 바꾸면 **코드 수정 없이 `.env` 로 교체**할 수 있게
> 전부 환경변수로 뺐습니다 (`XAI_IMAGE_PATH`, `XAI_VIDEO_PATH` 등).

## 알아두기 (한계 & 팁)

- **옷 재현 방식**: 그록 이미지 생성은 (현재 스펙상) 텍스트→이미지가 기본이라,
  업로드한 옷을 *비전으로 정밀 묘사*한 뒤 그 묘사대로 다시 그립니다.
  → 색/종류/실루엣은 잘 맞지만 프린트·로고까지 **픽셀 단위로 100% 동일**하진 않습니다.
  전용 가상피팅(try-on) 모델이 필요하면 ②단계만 교체하면 됩니다.
- **모델 일관성**: 시드 고정 API 가 없으면 컷마다 미세하게 달라질 수 있습니다.
  `appearance` 문구를 더 구체적으로 쓰면 일관성이 올라갑니다.
- **영상 응답 형태**: 동기(바로 URL) / 비동기(job 폴링) 둘 다 대응합니다.
  실제 응답 키가 다르면 `xai_client.py` 의 `_extract_video_url` 만 손보면 됩니다.
- **네트워크**: 이 앱은 `api.x.ai` 로 직접 나갑니다. 방화벽/프록시에서 허용되어야 합니다.
