# 안산 의원 활동 모니터링 대시보드

안산 지역 국회의원 · 경기도의원 · 안산시의원의 최근 의정활동을 한눈에 보는 정적 웹 대시보드입니다.
지역 주민이 브라우저에서 바로 열어볼 수 있도록 **단일 HTML 파일**(외부 의존성 없음)로 만들어졌습니다.

## 미리보기

- 모니터링 의원 30명 (국회 3 · 도의원 8 · 시의원 19)
- 급별(국회/도의원/시의원) · 정당별 필터
- 의원 이름 클릭 → 최근 90일 확인 보도와 기사 링크
- 라이트/다크 모드 자동 대응, 모바일 반응형

## 보기 방법

### 1) 로컬에서 바로 열기
`index.html` 을 브라우저로 열면 됩니다. 빌드·서버 불필요.

### 2) 웹으로 공개 (GitHub Pages)
저장소에 포함된 워크플로우(`.github/workflows/deploy-dashboard.yml`)가
`ansan-dashboard/` 폴더를 GitHub Pages 로 자동 배포합니다.

최초 1회 설정:
1. GitHub 저장소 → **Settings → Pages**
2. **Source** 를 **"GitHub Actions"** 로 지정
3. 이후 이 폴더에 변경을 push 하면 자동 배포됩니다.

배포 주소: `https://<사용자명>.github.io/<저장소명>/`

## 데이터 기준

- **지표 = 최근 90일 확인 보도 건수** — 네이버 검색 '건수'가 아니라, 해당 의원에 관한
  기사인지 실제로 확인한 기사만 집계한 표본 수치입니다.
- 로스터: 6·3 지방선거 당선인 명단 및 원구성 보도 기준(2026.7)
- 출처: 네이버 뉴스 검색

## 구조

```
ansan-dashboard/
  index.html   ← 대시보드 본체 (데이터 · 스타일 · 스크립트 모두 포함)
  README.md
```

의원 데이터는 `index.html` 안의 `M` 배열에서 관리합니다. 의원 추가/수정이나
기사 갱신은 이 배열을 편집하면 됩니다.
